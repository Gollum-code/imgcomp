能做什么

按目标体积压缩

指定 ≤500KB / ≤2MB，自动二分质量逼近目标，而不是让你手调质量参数猜大小。

人眼级质量把关

SSIM 感知对比防过度压缩：体积达标但质量崩了？宁大勿糊，自动标 UNMET 并保留原画质。

WebP / AVIF 转换

JPG/PNG 一键转 WebP/AVIF，体积比 JPEG 小 30–70%，电商和网页提速利器。

批量 + 递归目录

多线程并行，整个文件夹连同子目录一次处理完，带进度条和前后对比报告。

桌面图形界面

拖拽导入、原图/压缩后并排预览对比、逐行结果表，不懂命令行也能用。

完全本地 · 零成本

单文件 8MB，不联网不上传，压缩引擎全部开源免费，你的图不出你的电脑。

常见问题

图片会上传到服务器吗？

不会。imgcomp 完全在本地运行，压缩全程不联网、不上传，图片不出你的电脑。

「压到 ≤500KB 但质量变糊」怎么办？

imgcomp 内置 SSIM 质量把关。当某个大小必须以牺牲画质为代价时，它会保留原画质并把文件标为 UNMET，绝不为了体积毁图。

免费版和 Pro 版有什么区别？

免费版提供固定质量压缩和每次 10 张的限制，适合偶尔用。Pro 解锁按目标体积压缩、无限批量、WebP/AVIF 转换，一次买断终身使用。

支持什么格式？

输入 JPG / PNG / WebP；输出支持 JPG / PNG / WebP / AVIF。

命令行版本开源吗？

核心 CLI 开源，欢迎开发者把 imgcomp 集成到自己的工作流里。
