隐私政策

最后更新：2026-10-04

imgcomp 是一款本地运行的图片压缩工具。我们以简单、透明的方式处理数据：你的图片几乎从不离开你的设备。

1. 我们收集哪些数据

图片内容：不收集。压缩完全在你自己的设备上进行。你的图片、文件夹和压缩结果不会上传到任何服务器，也不会被我们访问。

许可证激活数据：当你激活 imgcomp Pro 许可证时，我们（或我们的授权服务）会处理以下信息以验证许可证：

  • 你输入的许可证密钥
  • 当前时间戳（用于离线宽限期检查）
  • 一个匿名设备标识符，用于将许可证绑定到你授权的设备数量（3 台）

这些数据仅用于验证你的购买、执行许可证密钥的激活限制（3 台设备），以及通过定期（约每 3 天）的在线检查确认许可证仍然有效。离线宽限期最长 30 天。

2. 许可证数据存储在哪里

激活后，许可证密钥存储在你设备操作系统的安全凭据存储中（Windows Credential Manager / macOS Keychain / Linux libsecret），而不是明文磁盘文件。我们不保存你的许可证密钥副本。

3. 我们不使用 Cookie 或广告

imgcomp 网站不使用跟踪 Cookie，不投放广告，不包含第三方分析跟踪器。本网站仅由 GitHub Pages 托管。

4. 第三方

购买 imgcomp Pro 通过 Creem 处理，支付由 Stripe 处理。你的支付信息由这些平台根据其自身的隐私政策处理，我们不会收到或存储你的完整支付卡号。
